## Codes tarifaires

| Code | Signification |
|---|---|
| `PUB` | Prix public, sans remise |
| `NEG` | Prix négocié annuel, révisé chaque 1er janvier |
| `PROMO` | Prix promotionnel, valable jusqu’à la date indiquée dans le fichier |
