# Spec reçue : annulation d’une commande

1. Un client peut annuler une commande récente.
2. L’annulation se fait depuis l’API.
3. Une commande déjà partie ne peut pas être annulée.
4. Le client est prévenu de l’annulation.
5. Les commandes annulées n’apparaissent plus.
6. Une annulation est traitée rapidement.
